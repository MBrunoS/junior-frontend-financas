# MB Finanças — Júnior Front-end

Materiais oficiais do projeto incremental do curso Júnior Front-end da
[MB Academy](https://github.com/MBrunoS/mb-academy).

## Como usar

- `student-starter/`: scaffold limpo para iniciar a primeira sprint;
- `sprints/`: enunciados e critérios de aceite;
- `kit/`: contrato OpenAPI, API local, fixtures e testes de contrato;
- `reference-solution/`: cliente React integrado para consulta posterior.

```bash
git clone https://github.com/MBrunoS/junior-frontend-financas.git
cd junior-frontend-financas/student-starter
pnpm install
pnpm dev
```

Consulte [Releases](https://github.com/MBrunoS/junior-frontend-financas/releases)
para baixar as tags imutáveis `sprint-N-materials`. Elas contêm os materiais da
etapa; seu código acumulado deve viver em um repositório da sua conta. Tente
implementar antes de abrir a referência.

## API local

Em outro terminal:

```bash
cd kit
pnpm reference:api
```

A API abre em `http://localhost:3333`. Conta: `ana@mbacademy.dev`; senha:
